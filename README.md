# Python Practice Repository

This repository contains beginner-to-intermediate Python practice scripts, exercises, and mini projects.

## File Descriptions

- `car.py` - Defines a `Car` class used in object-oriented programming examples.
- `example.py` - Utility module with simple geometry and math helper functions.
- `p01.py` - Basic print statement example.
- `p02.py` - Intro to variables and basic data types.
- `p03.py` - User input basics.
- `p03_01Exr.py` - Mad-libs style adjective/noun exercise.
- `p03_02EExr.py` - Rectangle area calculation exercise.
- `p03_03Exr.py` - Simple shopping/quantity/total price exercise.
- `p04.py` - Math module and arithmetic operation examples.
- `p04_01Exr.py` - Circle measurement exercise using `math`.
- `p05.py` - Conditional statements (`if`, `elif`, `else`) practice.
- `p06_Calculator.py` - Basic command-line calculator (`+`, `-`, `*`, `/`).
- `p07_Weight_Converter.py` - Weight converter between units.
- `p08_Temp_Convertion.py` - Temperature converter between Celsius and Fahrenheit.
- `p09.py` - Logical operators and condition checks.
- `p10.py` - String slicing and indexing basics.
- `p10_Exr.py` - Username slicing/formatting exercise.
- `p11.py` - String methods and text formatting examples.
- `p11_Exr.py` - Email parsing and username/domain extraction exercise.
- `p12.py` - Format specifiers for numbers and text output.
- `p13.py` - `while` loop practice with input validation.
- `p14_C-I_Calculator.py` - Compound interest calculator.
- `p15.py` - `for` loop and range iteration examples.
- `p16.py` - Nested loops and pattern printing.
- `p16_Exr.py` - Countdown timer exercise using `time`.
- `p17.py` - List operations and list methods.
- `p17_Exr.py` - Interactive list builder exercise.
- `p18.py` - Tuple usage examples.
- `p18_Exr.py` - 2D tuple/number pad style data structure exercise.
- `p19_Quiz_Game.py` - Console quiz game with score tracking.
- `p20.py` - Dictionary basics and operations.
- `p20_Exr.py` - Shopping cart/menu exercise using dictionaries.
- `p21.py` - Random number generation examples.
- `p21_Dice_Roll.py` - Dice rolling simulator with ASCII dice art.
- `p21_Encryption.py` - Simple substitution/cipher style encryption practice.
- `p21_Exr.py` - Random-based exercise script.
- `p21_RPS_game.py` - Rock-Paper-Scissors game.
- `p22.py` - Function definitions and parameter usage examples.
- `p23.py` - Default arguments and function call behavior examples.
- `p24.py` - Keyword arguments and reusable helper function examples.
- `p25.py` - Iterables and membership/iteration examples.
- `p26.py` - String/list searching and indexing examples.
- `p27.py` - List comprehensions and transformed list creation.
- `p28.py` - `math` module utilities and numeric function examples.
- `p29.py` - Scope examples (`local`, `global`) and function behavior.
- `p30.py` - Module function example with `main()` pattern.
- `p31.py` - Imports from `p30.py` and module usage practice.
- `p32.py` - Class import and object usage with `Car`.
- `p33.py` - Class definition and object-oriented programming example.
- `p34.py` - Lambda function examples.
- `p35.py` - `sort()` and custom sorting with objects/examples.
- `p36.py` - Recursion examples (`walk`, `factorial`).
- `p37.py` - Exception handling with `try/except`.
- `p38.py` - File writing example.
- `p39.py` - File reading/path handling example.
- `p40.py` - Time/date or timing-related practice script.
- `tempCodeRunnerFile.py` - Temporary runner/debug file created by the editor.
